## The joke

> My dad started a band called The Leftovers. He says they only play reheated hits.

One original one-line dad joke (81 characters, within the 140-character limit).
The pun: a band named after leftovers can only play *reheated* hits — the
punchline lands in the last two words, as a dad joke should.

## How it works

`main.ts` (Node 22+, standard library only, no network) validates the joke is
1–140 characters, then writes it to `$OUTPUT_DIR/entry.txt` (default `/output`).

## Run it

```sh
OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
